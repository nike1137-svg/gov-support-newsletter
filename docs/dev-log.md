# 4단계 자동 검수 · 예외 처리 — 같은 날 이어서

증명 스크립트(`tools/prove_verify.py`)를 먼저 돌렸다. 틀린 요약을 일부러 넣어 걸러지는지 실제 LLM 으로 본다.

| 시점 | 드러난 것 | 원인 | 고친 것 |
|---|---|---|---|
| 증명 1차 **3/8** | 정상 요약 A · 변조 B · D 가 '검수 불가' | 검수자 인용을 글자 그대로만 인정 → 날짜를 '9월 8일'로 바꿔 옮긴 것까지 거부 → 3회 재시도 후 실패 | 인용 글자 일치는 강제하지 않고, 날짜·금액 정규화로 느슨하게 대조해 '약한 인용' 경고로만 남김 |
| 〃 | F(월 30만 원 × 6개월 = 180만 원)를 근거 없음 판정 — 문제 칸에 "계산한 값임"이라고 스스로 적고도 | 지시("계산된 값은 근거 있음")를 LLM 이 일관되게 따르지 않음 | 계산 확인을 코드로: 본문 금액 × 본문 기간·횟수로 나오는 값이면 코드가 근거 있음으로 바로잡고 `corrected_by_code` 에 기록. 50만 원처럼 안 나오는 값은 그대로 불합격 |

| 증명 2차 **8/8** | 정상 통과 · 금액/마감일/없는 조건/나이 변조 전부 불합격 · 계산 금액 오탐 없음 · 재생성 후 변조값 없이 통과 · 검수 LLM 실패 시 발행 안 함 | | |
